# Trajectory V2 — единая визуальная система

## Цель

Собрать страницы Trajectory в цельный продукт на основе пользовательских Design System Prompt, сохранив функциональность, маршруты, API и данные. Общие нейтральные токены едины; акцент и некоторые параметры ритма задаются контекстом страницы.

## Общая основа

- Тёмная рабочая тема: фон `#030303`, поверхности `#000000` / `#333333`.
- Текст: `#ffffff`, вторичный `#dddddd`, приглушённый `#999999`.
- Границы: `#484848`, сильные разделители `#999999`.
- Roboto 400/700; fallback: Inter/system-ui.
- Основная ширина контента: 1366px.
- Базовая модульная сетка: 2px. Элементы обычно разделяются 8px.
- Кнопки/поля: радиус 8px. Основные карточки: 8px; карточки главной могут использовать 16px.
- Плоская иерархия: тени и blur отключаются, кроме осознанных overlay-паттернов.
- Контраст важнее буквального следования противоречивым значениям в исходных prompt.

## Страничные акценты

| Раздел | Акцент | Применение |
|---|---|---|
| Главная | `#fe5b61` | Основное действие/фокус |
| Профессии и направления | `#fbe600` | Основное действие/фокус |
| Каталог вузов | `#fbe600` | Основное действие/фокус; секции разнесены до 84px |
| Страница университета | `#edebfa` | Небольшие decision points; текст на нём тёмный для читаемости |
| Программы | `#fe5b61` | Основное действие/фокус |
| Олимпиады | `#fe5b61` | Основное действие/фокус; заголовок крупнее на странице каталога |

Акцент страницы не превращается в заливку больших областей. Вспомогательные палитры (фиолетовый, второй синий/красный) не используются как дополнительные декоративные акценты.

## Нормализация несогласованных исходных prompt

1. Некоторые prompt одновременно требуют тёмную тему и белый canvas/белые поля. В Trajectory принят тёмный canvas и светлый текст; отдельные светлые контролы допускаются только когда это предусмотрено реальным экраном и сохраняется контраст.
2. Белый текст на жёлтом или бледно-голубом акценте плохо читается. Для этих заливок используется тёмный текст.
3. Размеры body 21–24px и line-height 0.81 встречаются в prompt как машинно извлечённые значения. Они не применяются как глобальный текстовый стиль: базовый интерфейсный текст 16px, тело длинного чтения — 16–18px, крупные значения остаются для заголовков/статистики.
4. Радиусы и отступы отличаются по страницам; общая система использует 8px controls/cards, 16px для крупных карточек главной, 16px как базовый padding карточки, 32px — для больших информационных блоков.
5. Личный кабинет в референсе открывается overlay/modal. В Trajectory это исследуется как UX-паттерн; существующие маршруты `/profile`, `/settings`, `/auth` не удаляются.

## Страницы и источники референсов

- Главная — Design System Prompt «Абитуриенту 2027».
- Профессии/направления — «Список профессий: выбери свою профессию».
- Каталог вузов — «Вузы России 2026».
- Страница университета — «Синергия: Московский университет Синергия».
- Каталог программ — «Проходные баллы 2026…».
- Каталог олимпиад — «Олимпиады школьников».
