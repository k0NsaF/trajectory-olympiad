# VISUAL.md — «Траектория в олимпиаду»

## 0. Назначение документа

Единый источник правды по визуальному стилю, структуре экранов, компонентам, состояниям и поведению интерфейса. Документ написан так, чтобы ИИ-ассистент или разработчик мог по нему воспроизвести интерфейс без дополнительных вопросов.

Область действия: только визуал и UX. Техническая часть (БД, API, логика генератора) — в TECH.md.

---

## 1. Общие принципы

- Стиль: технологичный, дружелюбный, но не «детский». Академическая строгость в данных + мягкие акценты в навигации.
- Цвет обозначает смысл. Не красить каждую карточку в синий/фиолетовый. Акцент — только для действия, статуса или ключевого показателя.
- Две темы: тёмная (основная для демо) и светлая. Переключение — иконка солнца/луны в шапке.
- Адаптив: mobile-first. Всё, что открывается на десктопе, должно работать на телефоне без горизонтального скролла.
- Анимации: 150–250 мс, плавные, без навязчивости. Не анимировать всё подряд.
- Обращение к пользователю: на «ты». Дружелюбно, но без сюсюканья.
- Юридическая осторожность: везде, где есть льготы, — дисклеймер «проверяй локальные акты вуза».

## 4. Компоненты

### 4.1. Скругления, границы, тени

| Элемент | Значение |
|---|---|
| Карточки | border-radius: 16px |
| Модалки / bottom sheet | border-radius: 20px (верхние углы для sheet) |
| Кнопки | border-radius: 12px |
| Инпуты | border-radius: 10px |
| Бейджи | border-radius: 999px (pill) |
| Границы | 1px solid var(--border) |
| Тени (тёмная) | 0 4px 16px rgba(0,0,0,0.25) — очень слабая |
| Тени (светлая) | 0 4px 16px rgba(23,35,59,0.08) |

### 4.2. Отступы (spacing scale)

Базовая сетка — 4 px. Использовать кратные: 4, 8, 12, 16, 20, 24, 32, 40, 48.

- Внутренние отступы карточек: 16–20 px.
- Отступ между карточками: 12–16 px.
- Отступ секций: 24–32 px.
- Горизонтальные отступы страницы: 16 px (mobile), 24–32 px (desktop).

### 4.3. Кнопки

| Тип | Стиль | Размер |
|---|---|---|
| Primary | Фон --accent, текст белый | Высота 48 px (mobile 44 px), padding 0 20 px, 12px radius |
| Secondary | Прозрачный фон, граница 1px var(--border), текст --text | Тот же |
| Ghost | Без фона и границы, текст --accent | Тот же |
| Danger | Фон --error (10% opacity), текст --error | Тот же |
| Icon button | Квадрат 40×40 px, 10px radius, фон --surface | — |

Состояния:
- Hover: затемнение/осветление на 8%.
- Active: масштаб 0.98.
- Disabled: opacity: 0.4, cursor: not-allowed.
- Loading: спиннер (Lucide Loader2 с анимацией) вместо текста, ширина фиксирована.

### 4.4. Поля ввода

- Фон --surface, граница 1px var(--border), 10px radius, высота 48 px.
- Placeholder — --text-muted.
- Focus: граница --accent, лёгкое свечение 0 0 0 3px rgba(76,131,255,0.15).
- Error: граница --error, текст ошибки под полем (Caption, --error).

### 4.5. Бейджи статусов

Формат: pill, фон — цвет с прозрачностью 15%, текст — тот же цвет (насыщенный).

| Статус | Цвет (dark / light) | Иконка (Lucide) |
|---|---|---|
| «Подходит тебе» | --success | CheckCircle2 |
| «Можно успеть» | --accent | Clock |
| «Не подходит» | --error | XCircle |
| «Скоро дедлайн» | --warning | AlertTriangle |
| Уровень I–IV | --accent-2 | — (только текст «Уровень I») |
| «Проверено» | --success | BadgeCheck |
| «Получен» / «Пройден» | --success | Check |

### 4.6. Иконки

- Библиотека: Lucide.
- Размеры: 16 px (в тексте), 20 px (в кнопках), 24 px (в навигации), 32–40 px (в пустых состояниях).
- Цвет: наследует currentColor, кроме акцентных иконок в карточках (там — --accent / --accent-2).

### 4.7. Анимации

- Длительность: 150–250 мс.
- Easing: cubic-bezier(0.4, 0, 0.2, 1).
- Ховеры: transition: all 150ms.
- Появление модалок/sheet: opacity + translateY 200 мс.
- Не анимировать списки целиком — только появление новых элементов.

## 5. Структура приложения (7 разделов)

### 5.1. Навигация

Десктоп (≥1024 px):
- Боковая панель слева, ширина 240 px, сворачиваемая до 72 px (только иконки).
- Вверху — логотип «Траектория» + иконка Route.
- Пункты меню: иконка + подпись.
- Активный пункт: фон --surface, текст --accent, слева — полоска 3 px --accent.
- Внизу панели — переключатель темы и профиль.

Мобильный (<1024 px):
- Нижняя таб-панель, 5 иконок: Траектория, Каталог, Календарь, Вузы, Ещё.
- «Ещё» открывает bottom sheet: Достижения, ИИ-консультант, Профиль.
- Активный пункт: иконка и подпись --accent.

Шапка (оба режима):
- Слева — логотип (на мобильном) или заголовок экрана.
- Справа — переключатель темы (иконка Sun / Moon), аватар (если авторизован) или кнопка «Войти».

### 5.2. Переключатель темы

- Иконка Sun (в тёмной теме) / Moon (в светлой) в шапке.
- По клику — выпадающее меню:
  - «Светлая» (иконка Sun)
  - «Тёмная» (иконка Moon)
  - «Системная» (иконка Monitor)
- Активный пункт отмечен галочкой.
- Выбор сохраняется в localStorage.

### 5.3. Список разделов

| № | Раздел | Иконка (Lucide) | Назначение |
|---|---|---|---|
| 1 | Моя траектория | Route | Главный персональный экран |
| 2 | Каталог олимпиад | Trophy | Поиск и фильтры |
| 3 | Календарь | Calendar | Все этапы и дедлайны |
| 4 | Вузы и льготы | GraduationCap | Проверка преимуществ |
| 5 | Мои достижения | TrendingUp | Результаты и прогресс |
| 6 | ИИ-консультант | MessageCircle | Ответы по базе |
| 7 | Профиль | User | Настройки и цели |

## 6. Экран №1. Онбординг (квиз)

### 6.1. Общая структура

- Один вопрос на экран.
- Сверху — прогресс-бар из 5 сегментов + подпись «Шаг X из 5» и процент (например, «40%»).
- Кнопка «Продолжить →» внизу (Primary, на всю ширину), неактивна, пока не выбран ответ.
- Кнопка «Назад» (иконка ArrowLeft) в левом верхнем углу (кроме первого шага).
- После каждого шага — подсказка «Зачем это нужно» под вопросом, Caption, --text-muted.

### 6.2. Шаги

| Шаг | Вопрос | Тип выбора | Подсказка «Зачем» |
|---|---|---|---|
| 1 | «В каком ты классе?» | Чипы 7–11 (один выбор) | «Мы учитываем твой класс, чтобы не рекомендовать олимпиады, в которых ты не можешь участвовать». |
| 2 | «Твой регион обучения» | Поиск + список (один выбор) | «В некоторых регионах есть свои площадки и льготы». |
| 3 | «Какие предметы тебе интересны?» | Сетка карточек 2×N с иконками (мультивыбор) | «Подберём олимпиады под твои интересы». |
| 4 | «Какой вуз рассматриваешь?» | Поиск + список (один выбор, опционально, можно пропустить) | «Покажем льготы именно для этого вуза». |
| 5 | «Какое направление тебе интересно?» | Список направлений вуза (опционально, можно пропустить) | «Уточним, какие олимпиады дают преимущество на этом направлении». |

### 6.3. Детали шага 3 (предметы)

Сетка карточек 2 колонки (mobile) / 4 колонки (desktop):
- Иконка предмета (Lucide: Calculator — математика, Code — информатика, Atom — физика, Dna — биология, FlaskConical — химия, BookOpen — русский, Landmark — экономика, Globe — история).
- Название предмета.
- Состояние выбора: фон --surface, граница --accent 2 px, галочка в углу.

### 6.4. Дополнительные (опциональные) вопросы

После шага 5 — сворачиваемый блок «Хочешь уточнить?»:
- «Участвовал ли ты в олимпиадах раньше?» (Да/Нет)
- «Есть ли уже дипломы?» (Да/Нет)
- «Как оцениваешь свою подготовку?» (Начальный / Средний / Продвинутый)

### 6.5. Экран загрузки после квиза

- Центрированный блок.
- Иконка Brain в квадрате с фоном --surface, --accent.
- H1: «Строим твою траекторию».
- Подзаголовок: «Анализируем твои возможности…».
- Список чек-пойнтов с иконкой CheckCircle2 (--success), появляются по очереди с задержкой 300 мс:
  1. Проверяем подходящие олимпиады
  2. Анализируем сроки регистрации
  3. Сопоставляем условия вузов
  4. Формируем персональный план

### 6.6. Предварительный результат (до регистрации)

- Бейдж «Траектория сформирована» (--success).
- H1: «Твой путь начинается!».
- Подзаголовок: «Мы подобрали олимпиады на основе твоего класса, интересов и цели».
- Две карточки-показателя: 8 Подходящих олимпиад, 3 Ближайших события.
- Список «Твои рекомендации» (2–3 карточки).
- Блок «Не потеряй свой план!»: «Создай аккаунт, чтобы сохранить траекторию, отмечать достижения и получать напоминания».
- Кнопка Primary: «Сохранить мою траекторию →».
- Подпись внизу: «Демонстрационные данные».

## 7. Экран №2. Моя траектория (главная)

### 7.1. Шапка

- Приветствие: «Привет, [Имя]! 👋» (H1, 28–32 px).
- Подзаголовок: «Продолжим путь к твоей цели?» (Caption, --text-muted).

### 7.2. Блок «Твоя цель»

- Карточка (--card, 16px radius, 1px border).
- Слева сверху — Caption «ТВОЯ ЦЕЛЬ».
- Справа сверху — бейдж «11 класс» (--surface, --text-muted).
- H2: название вуза (например, «МФТИ»).
- Под ним — Body: направление («Прикладная математика и информатика»).

### 7.3. Блок показателей (3 колонки)

Три карточки в ряд (mobile — 3 в ряд с уменьшенным шрифтом или горизонтальный скролл):

| Показатель | Подпись |
|---|---|
| 8 | Подходящие олимпиады |
| 3 | Ближайшие события |
| 2 | Активные регистрации |

- Цифра: H1-размер, --text-h, tabular-nums.
- Подпись: Caption, --text-muted.

### 7.4. Блок «Твой план на сезон»

- Заголовок H3 + справа ссылка «Все этапы →» (--accent).
- Вертикальный таймлайн (нумерованные шаги):
  1. Выполнено (бейдж --success) — «Подбор олимпиад»
  2. Сейчас (бейдж --accent) — «Регистрация на Физтех»
  3. Далее (бейдж --surface, текст --text-muted) — «Отборочный этап»
- Между шагами — вертикальная линия --border.

### 7.5. Блок «Следующий важный шаг»

- Карточка с иконкой AlertCircle (--accent).
- Caption: «СЛЕДУЮЩИЙ ВАЖНЫЙ ШАГ».
- H3: «Зарегистрироваться на олимпиаду».
- Body: «Проверь сроки регистрации и требования к участникам».
- Кнопка Primary на всю ширину: «Открыть олимпиаду →».

### 7.6. Блок «Рекомендации для тебя»

- Заголовок H3.
- Список карточек (2–3):
  - Слева — иконка Trophy в квадрате --surface с --accent.
  - Название олимпиады (Body medium).
  - Предметы через · (Caption, --text-muted).
  - Справа — шеврон ChevronRight (--text-muted).

### 7.7. Плавающая кнопка ИИ

- В правом нижнем углу: круглая кнопка 56×56 px, фон --accent, иконка MessageCircle белая.
- Над ней — всплывающая подсказка: «ИИ-помощник. Чем могу помочь?» (карточка --card, тень). Исчезает через 5 сек или при клике.
- На мобильном — кнопка поднята над нижней навигацией на 16 px.

## 8. Экран №3. Каталог олимпиад

### 8.1. Шапка

- H1: «Каталог олимпиад».
- Подзаголовок: «Найди возможности, которые приблизят тебя к поступлению».

### 8.2. Поиск

- Строка поиска: иконка Search слева, плейсхолдер «Найти олимпиаду…», высота 48 px.
- При вводе — фильтрация в реальном времени (debounce 300 мс).

### 8.3. Фильтры (чипы)

- Горизонтальный скролл (mobile) / перенос (desktop).
- Первый чип — «Все предметы» (активный: фон --accent, текст белый).
- Остальные: «Математика», «Информатика», «Физика», «Биология», «Химия», «Экономика», «Русский язык», «История».
- Неактивный чип: фон --surface, текст --text.
- Кнопка «Фильтры» (иконка SlidersHorizontal) справа — открывает bottom sheet (mobile) / поповер (desktop).

### 8.4. Bottom sheet «Фильтры»

Поля:
- Предмет — мультивыбор чипами.
- Класс — чипы 7–11.
- Уровень — чипы I, II, III, IV.
- Статус регистрации — «Открыта», «Скоро», «Закрыта».
- Формат — «Онлайн», «Очно», «Смешанно».
- Возможные льготы — тумблер «Только с льготами».
- Подходит для выбранного вуза — тумблер.

Внизу — две кнопки: «Сбросить» (Ghost) и «Применить» (Primary).

## 9. Экран №4. Календарь

### 9.1. Шапка

- H1: «Календарь».
- Переключатель режимов: «Месяц» / «Список» (сегментированный контрол, активный — --surface с --text-h).

### 9.2. Режим «Месяц»

- Заголовок месяца: «Ноябрь 2026» + стрелки ChevronLeft / ChevronRight.
- Дни недели: Пн–Вс (Caption, --text-muted).
- Сетка 7×N.
- Каждый день — ячейка с числом.
- Под числом — до 3 цветных точек (если событий больше — «+N»).
- Текущий день — обводка --accent 2 px.
- Выбранный день — фон --surface.
- Цвета точек:
  - Синий --accent — регистрация
  - Фиолетовый --accent-2 — отборочный этап
  - Зелёный --success — заключительный этап
  - Оранжевый --warning — скоро дедлайн
  - Серый --text-muted — завершено

### 9.3. Блок «Ближайшие события» (под календарём)

- Заголовок H3.
- Список карточек:
  - Слева — бейдж с датой (день крупно, месяц мелко), фон --surface.
  - Тип события (цветной текст).
  - Название олимпиады.
  - Шеврон вправо.

### 9.4. Режим «Список»

- Группировка по датам: «18 ноября», «28 ноября»…
- Каждое событие — карточка, как в блоке «Ближайшие события».
- Возможность отметить выполненным: чекбокс справа.

### 9.5. Клик по дате

- Открывает bottom sheet (mobile) / поповер (desktop) со списком событий этого дня.
- Каждое событие — кликабельно → карточка олимпиады.

### 10.3. Сравнение вузов (как в маркетплейсах)

Добавление:
- На карточке вуза — кнопка/чекбокс «В сравнение» (иконка Scale).
- При добавлении — липкая панель снизу:
  - «Выбрано N вузов» (N = 1–5).
  - Чипы с названиями вузов и иконкой X для удаления каждого.
  - Кнопка «Сравнить» (Primary).
  - Кнопка «Очистить» (Ghost).
- Лимит — 5 вузов. При попытке добавить шестой — тост «Можно сравнить не более 5 вузов».

Страница сравнения (модалка или отдельный экран):
- Таблица:

| Условие | Вуз А | Вуз Б | Вуз В |
|---|---|---|---|
| БВИ | ✅ | ❌ | ✅ |
| 100 баллов | ✅ | ✅ | ✅ |
| Доп. баллы | ✅ | ✅ | ❌ |
| Порог ЕГЭ | 80 | 75 | 85 |

- У каждой колонки — кнопка «Удалить» (X).
- Под таблицей — блок «Что это значит для тебя» (если ИИ подключён): краткий вывод на основе профиля.
- Если ИИ не подключён — блок скрыт.

Мобильный: сравнение — отдельный экран (не модалка), таблица скроллится горизонтально, первый столбец закреплён.

## 12. ИИ-консультант (чат)

### 12.1. Точки входа

- Плавающая кнопка (главная, каталог).
- Кнопка «Помочь с выбором» (каталог).
- Кнопка «Объяснить условия поступления» (страница вуза).
- Кнопка «Оптимизировать мой план» (траектория).
- Пункт в навигации.

### 12.2. Десктоп

- Всплывающее окно в правом нижнем углу: ширина 380 px, высота 600 px.
- Шапка окна:
  - Иконка MessageCircle в квадрате --surface.
  - Заголовок «Траектория AI» (H3).
  - Статус «Онлайн» (Caption, --success) с зелёной точкой.
  - Справа — кнопки свернуть (Minus) и закрыть (X).
- История сообщений (скролл):
  - Сообщение ассистента: слева, фон --surface, 12px radius, padding 12–16 px, max-width 85%.
  - Сообщение пользователя: справа, фон --accent, текст белый, 12px radius.
- Поле ввода внизу: инпут + кнопка отправки (ArrowUp) в круге --accent.
- Дисклеймер под полем ввода (Caption, --text-muted): «ИИ может ошибаться. Важные условия проверяй по официальным источникам».

### 12.3. Мобильный

- Bottom sheet, открывается на 90–100% высоты экрана.
- Верхняя ручка (drag handle) — полоска 40×4 px, --border, по центру.
- Свайп вниз — закрыть; возврат на ту же страницу, где был.
- Кнопка «Назад» (ArrowLeft) в шапке чата.
- Всё остальное — как на десктопе.

### 12.4. Контент чата

Приветствие:
- Аватар ассистента (иконка MessageCircle в квадрате --surface).
- H3: «Привет! Чем помочь? 👋».
- Body: «Я помогу разобраться в олимпиадах, подобрать подходящие соревнования и узнать, какие льготы они могут дать при поступлении».

Быстрые вопросы (чипы под приветствием):
- «Какие олимпиады мне подойдут?»
- «Что даёт диплом победителя?»
- «Как подготовиться к олимпиаде?»
- «Какие регистрации скоро закроются?»

Ответ ассистента:
- Структурированный текст: короткие абзацы, нумерованные шаги.
- Внизу — блок «Источники» (Caption, --text-muted): «Перечень РСОШ · Правила приёма вуза · Официальный календарь».

### 12.5. Контекстность

- На странице олимпиады — чат знает, о какой олимпиаде речь.
- В календаре — может ответить про ближайшие дедлайны.
- На странице вуза — про льготы.
- В траектории — про оптимизацию плана.
- В шапке чата отображается контекст: например, «Контекст: Олимпиада "Физтех"».

## 14. Состояния и edge-cases

| Ситуация | Отображение |
|---|---|
| Нет подходящих олимпиад | Пустое состояние: иконка SearchX, «Пока ничего не нашли. Попробуй изменить фильтры или класс». |
| Регистрация закрыта | Бейдж «Не подходит» (ошибка). Не показывать «Можно успеть». |
| Нет авторизации | Баннер «Сохрани траекторию» с кнопкой «Создать аккаунт». |
| Ошибка загрузки | Плашка с текстом «Не удалось загрузить. Повторить» (кнопка). |
| Пустой календарь | «На этот месяц событий нет. Проверь следующий месяц». |
| Достижений нет | «Ты пока не добавил достижений. Начни с первой олимпиады». |
| Лимит сравнения | Тост «Можно сравнить не более 5 вузов». |
| Ошибка ИИ | «Не удалось получить ответ. Попробуй ещё раз». |

## 15. Тексты (тон)

- Обращение: на «ты».
- Дружелюбно, но без сюсюканья.
- Примеры: «Построить мою траекторию», «Сохранить мой план», «Проверь сроки», «Твой путь начинается».
- Дисклеймер везде, где есть льготы: «Проверяй локальные акты вуза».
